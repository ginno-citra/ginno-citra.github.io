Power BI projects

Dashboards built on ledger, log and sales data, with DAX, Power Query and drillthrough.

Customer aging dashboard

Power BI · DAX · Power Query

Shows which customers owe what, and for how long, from a customer ledger. Aging buckets are built with SWITCH in DAX and follow the billing month, advance payments are kept out of past-due totals, and a drillthrough page opens the invoice-level detail. It is a Power BI rebuild, with anonymized data, of the monthly Excel aging report that billers, the accounting supervisor and managers, and operations use at work.

Email delivery monitoring

Power BI · DAX · Row-level security · Excel

Tracks delivered and failed billing and receipt emails by project. The version used at work, by billers and accounting supervisors and managers, masks recipient emails and links to per-project Excel files on SharePoint, so billers no longer have to request the Excel file every month. This portfolio version adds dynamic row-level security, so each manager sees only their own projects.
